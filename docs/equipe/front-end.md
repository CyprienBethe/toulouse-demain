# Fiche de poste — Dev senior front-end

## Mission
Construire le site statique : carte, recherche, affichage des itinéraires, sélecteur de scénario et comparateur.

## Responsabilités
- Implémenter les maquettes validées, d'abord sur mobile.
- Intégrer la carte (MapLibre GL et tuiles OpenStreetMap gratuites), la recherche d'adresse et l'API du moteur.
- Garder le site léger : chargement rapide en 4G, pas de dépendance inutile.
- Déployer automatiquement sur l'hébergement statique gratuit à chaque modification validée.

## Standards
- Aucun traceur, aucun cookie publicitaire.
- Attribution des sources (OpenStreetMap, Tisséo, SNCF) visible sur la carte.
- Code lisible et commenté pour un débutant ; tests sur les fonctions de mise en forme des trajets.

## Livrables
Site en ligne, code source, guide de lancement en local.

## Travaille avec
UX (maquettes), architecte (contrat d'API), cybersécurité (en-têtes de sécurité), QA (tests).
